Paleta

Verde hondo de mercado como color de marca, ámbar-trigo (el "maná") reservado para la acción principal de cobrar. Rojo solo para anular.

Reglas táctiles

Todo botón operable mide 48 px o más. Las funciones de cada venta (buscar, granel, cobrar) están a un toque; lo administrativo vive fuera de esta pantalla. Números siempre tabulares para que los montos queden alineados.

Color por categoría

Cada tarjeta lleva una barrita de color según su categoría (verde frutas, ámbar abarrotes, azul bebidas, lila limpieza): la cajera ubica el producto por color antes que por texto.
